# Anemia-Level Classification

## Educational Data Science Course Project

Created in **2024** as part of my Data Science learning journey, this is a documentation-first public record of an earlier machine-learning learning exercise. It explored classification methods on an external dataset containing anemia-related variables.

## What was explored

- Data cleaning and categorical-feature preparation
- Logistic Regression, Decision Tree, Random Forest, Extra Trees, and Gradient Boosting experiments
- An experimental XGBoost approach on encoded target labels

## Medical-use limitation

This project is **not a medical device**, diagnostic tool, risk assessment, or clinical decision-support system. It must not be used to diagnose anemia or make healthcare decisions about any person.

## Important status

The original notebook and its outputs are intentionally not published here. The earlier exercise requires a clean, reproducible classification pipeline and a source/licence review before executable code can be responsibly shared.
